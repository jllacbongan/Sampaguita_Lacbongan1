# Finding the distance between two coordinate points

## Description

This Python program calculates the distance between two coordinate points using functions
from the math library.

## How to Run
- Download the file and open it in PyCharm
- Run the python file
- Enter the required points
- Wait for the calculated distance to be displayed

## Input Needed

Enter the following numbers:

- Point x1
- Point y1
- Point x2
- Point y2

## Sample Output
**Input**

Please enter your chosen numbers for each point:
- Point x1: 4
- Point y1: -1
- Point x2: 5
- Point y2: 6

**Output**

- The distance between 4, -1, 5 and 6 is:  7.07
